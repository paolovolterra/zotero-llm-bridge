# Istruzioni zotero-llm-bridge

Leggere `README.md` e `LOG.md` prima di modificare il CLI. Mantenere le scritture su Zotero attraverso l'API locale; non scrivere direttamente nei database. Non registrare chiavi API nei log, nei test o in Git. Verificare le modifiche con controlli proporzionati e registrare le modifiche sostanziali in `LOG.md`.
